# Changelog

All notable changes to SecureAuth Admin are tracked here.

## v1.0.0 - 2026-05-20

Initial public release.

### Added

- PHP/MySQL admin login gateway.
- First-admin setup flow.
- Password hashing with PHP password APIs.
- Strict sessions with idle and absolute expiry.
- CSRF protection for login, setup, OTP, and logout flows.
- IP-based login throttling.
- Optional email OTP verification through PHPMailer.
- Admin audit logs.
- Apache `.htaccess` protection for sensitive files and folders.
- MIT license.
- GitHub-ready README, project documentation, and security review.
