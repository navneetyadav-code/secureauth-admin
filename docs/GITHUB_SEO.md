# GitHub SEO And Engagement Checklist

GitHub discovery is not classic website SEO. The strongest signals are the repository name, description, topics, README, activity, release tags, license, and whether people can quickly understand what the project does.

## Recommended Repository Metadata

Use this exact short description in the GitHub About box:

```text
A lightweight PHP/MySQL admin authentication gateway with secure sessions, CSRF protection, OTP, throttling, and audit logs.
```

Recommended website field:

```text
https://github.com/navneetyadav-code/secureauth-admin
```

## Social Preview

GitHub lets you upload a social preview image from repository settings. Use:

```text
assets/images/github-social-preview.png
```

Path in GitHub:

```text
Settings -> General -> Social preview -> Edit -> Upload an image
```

Best display size is `1280 x 640`.

## Engagement Settings

Recommended settings:

| Setting | Recommendation |
| --- | --- |
| Issues | On |
| Discussions | On if you want questions and ideas |
| Wiki | Off unless you plan to maintain it |
| Projects | Optional |
| Sponsorships | Optional |
| Private vulnerability reporting | On |

## Launch Checklist

1. Add the recommended topics.
2. Upload the social preview image.
3. Create the GitHub Release for tag `v1.0.0`.
4. Pin the repository on your GitHub profile.
5. Add a short post on LinkedIn, X, Reddit, or dev communities.
6. Open 2-3 beginner-friendly issues with `good first issue`.
7. Keep improving the README with real screenshots when the UI changes.
