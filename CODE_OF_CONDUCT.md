# Code Of Conduct

SecureAuth Admin welcomes helpful, respectful collaboration.

## Expected Behavior

- Be clear, kind, and constructive.
- Focus feedback on the code, documentation, design, or security behavior.
- Help beginners learn without making them feel small.
- Keep security discussions responsible and private when sensitive.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Publishing private information or secrets.
- Posting exploit details for an unresolved sensitive vulnerability in public issues.
- Spam, low-effort promotion, or unrelated content.

## Reporting

For normal project behavior issues, open an issue or contact the repository owner through GitHub.

For sensitive security reports, follow [SECURITY.md](SECURITY.md).
